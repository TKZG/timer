# 同梱音源

5種類のWAVは `scripts/generate-audio.mjs` でこのプロジェクト用に合成したものです。第三者の録音、楽曲、音声サンプルは使用していません。

- rain.wav：ノイズと水滴の合成による雨音
- cafe.wav：声に似た遠いざわめきとカップの響きを模した合成音（会話の録音ではありません）
- white-noise.wav：ホワイトノイズ
- nature.wav：水辺と鳥の声を模した合成音
- lofi.wav：オリジナルのコード進行とビート

すべての音源は末尾2秒で滑らかにフェードアウトし、冒頭1秒でフェードインします。繰り返し時の急な音量変化を抑えるため、フェードはWAV自体に適用しています。

`npm run audio` で再生成できます。より自然な実録音源を使う場合は、利用・配布権限のある音源に差し替えてください。ファイル名や形式を変える場合は `src/types/pomodoro.ts` と `src/composables/useBgm.ts` も変更してください。
