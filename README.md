# still — 集中する時間

Vue 3 + TypeScriptのポモドーロタイマー。25分の集中と5分の休憩を自動で繰り返します。外部UIライブラリは使用していません。

## 起動

Node.js 22.12以降（または対応するNode.js 20.19以降）が必要です。

```sh
npm install
npm run dev
```

ターミナルに表示されるローカルURLを開きます。

```sh
npm test        # タイマー・音声制御・保存のテスト
npm run build  # TypeScriptの型チェックと本番ビルド
npm run preview
```

## 操作

- 開始、一時停止、再開、リセット、集中・休憩の手動切り替え。
- 自動切り替え時は実行を継続。手動切り替えとリセットでは停止。
- 集中を完了するとセッション数が増えます。手動操作では増減しません。
- BGMボタンで設定を開き、5種類の音・ON / OFF・音量を変更できます。
- 初期設定はBGM ON、雨音、音量35%。集中開始操作までは再生しません。
- BGMは集中時だけ再生。通知音はBGMのON / OFFと独立しています。
- BGM設定のみブラウザに保存します。再読み込み時はタイマーと完了数を初期化します。

音源はプロジェクト用の合成WAVを同梱しています。カフェ・自然音も録音ではなく合成音です。詳細と差し替え方法は [音源の説明](public/audio/README.md) を参照してください。外部への音声リクエストはありません。

ブラウザやOSが停止させた処理を正確な時刻に実行することは保証できません。復帰時に終了予定時刻から状態を再計算し、通知音は最大1回にまとめます。システム時計を手動変更すると `Date.now()` を使うため残り時間にも影響します。
